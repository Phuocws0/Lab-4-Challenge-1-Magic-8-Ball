# Lab 4: Challenge 1 - Magic 8 Ball

A TypeScript React Native version of the Magic 8 Ball lab. Tapping the ball chooses a different one of the five original answer images.

## Run on Android

```sh
cd source
npm install
npm run android
```

Requirements: Node.js 22.11 or newer, Java, Android Studio/SDK, and an Android emulator or device. Build a release APK with `cd source/android && ./gradlew assembleRelease`.

The release app was built and launched on the Pixel 7 Android emulator; tapping the ball changed the displayed answer. The local demo video is stored separately from this repository.
